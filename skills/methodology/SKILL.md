# 指标口径与复刻

## 查口径

1. `indicator_list` 列出全部指标及对应工具。
2. `methodology_get(topic)` 取完整口径：`fear_index` / `median_anchor` / `bias_rank` / `dividend_yield` / `macro_series`。
   离线时也可读本仓库 `methodology/*.md`（同一份内容的静态版）。
3. 回答时按「是什么 → 怎么算 → 参数 → 局限 → 历史上验证过什么」组织，局限和验证结论不能省略。

## 帮用户复刻

用户想在自己的环境里重算时：

1. 用 Python（pandas）按口径写出可运行代码，参数写成变量放在文件顶部，方便用户改。
2. 数据源让用户自己准备（如自己的 tushare token、akshare 或券商导出 CSV），不要假设我们提供原始行情。
3. 用 MCP 返回的读数做**对账**：同一天、同一指数，用户重算值与 `market_snapshot` / `fear_series` 的差异应很小；差异大时逐项检查样本起点、窗口、复权口径。

## 改造

用户想按自己的偏好改参数（如把 60 日乖离率改成 20 日、把中枢从全历史改成近十年滚动）时：
- 先指出改动会改变什么（如滚动窗口会让中枢跟着价格走、失去「长期锚」的意义）；
- 改完用历史数据对比新旧两版的差异，而不是只看最近一段。
