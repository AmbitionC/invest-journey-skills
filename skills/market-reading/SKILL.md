# A 股市场读数

用 `invest-journey` MCP 取数，给出**带口径的读数**，不要给买卖指令。

## 步骤

1. `market_snapshot` 取全貌：
   - 恐慌指数（0-100，越高越恐慌，看 `level` 分档；`intraday=true` 是盘中近似值，要说明）
   - 沪深300 / 中证红利 / 创业板指 / 科创50 相对长期中枢的偏离 `vs_median_pct`
   - 七个指数的 60 日乖离率与近十年排名
   - 中证红利股息率与分位（注意 `percentile_since`，窗口不是十年）
2. 需要趋势时补历史：`fear_series`（默认近一年）、`bias_series`、`macro_series`。
3. 解释任何数字之前，先用 `methodology_get` 确认口径，把**局限**一并告诉用户。

## 输出格式

- 一句话总结市场温度（偏冷 / 中性 / 偏热），说明依据哪几个数。
- 表格列出各指数位置；标出每个数的数据日期（`data_date`），日期旧于最新交易日要明说。
- 「这些数说明不了什么」小节：例如乖离率历史验证不适合作买卖信号、恐慌指数贪婪端在大顶失灵过。

## 边界（必须遵守）

- 读数不是建议。不要说「应该买 / 该卖 / 加仓到 X%」。
- 用户追问操作时，引导到 `strategy-builder`：由用户自己定规则和风险偏好，Agent 只帮他把规则写清楚、用历史数据检验。
- 末尾附一句：数据仅供研究参考，不构成投资建议。
