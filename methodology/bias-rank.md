# 60 日乖离率与近十年排名

乖离率 = 收盘相对 60 日均线的偏离；再看它在近十年（2500 个交易日滚动窗口）里排第几低 / 第几高。这是一个读数，不是买卖信号。

## 数据来源

七个指数日线：沪深300、中证红利、创业板指、科创50、上证50、中证500、中证1000。

## 计算方法

- 乖离率 = 收盘 ÷ 近 60 日收盘均值 − 1
- rank_low = 窗口内比今天更低的天数 + 1（1 = 近十年最低）
- rank_high = 窗口内比今天更高的天数 + 1（1 = 近十年最高）
- 窗口不足十年时用全部可算历史，但至少 250 天才给排名

## 参数

- 均线天数：60
- 排名窗口交易日：2500
- 最少样本：250

## 更新频率

交易日收盘后随日更计算。

## 局限

- 窗口是滚动的，不是全历史：全历史排名会被 2008、2015 的极端值永久锁死。

## 历史验证

- 六种用法全部验证失败：分位高尾、分位低尾、全历史排名、排名加止盈止损、滚动排名状态机、z 分数短线，均不能稳定跑赢。
- 涨到极值不能当卖出依据——历史上 A 股价格类极值更像动量（继续涨）而不是回归。
