# A 股恐慌指数（0-100）

参照 CNN Fear & Greed 框架，取 A 股可算的五个分量等权合成；分数越高越恐慌。是按日收盘计算的慢变量（市场体温），不是实时 VIX。

## 数据来源

tushare 沪深300 日线 + 全市场个股日线；2005-01 起逐日回填。

## 计算方法

- 动量：沪深300 收盘距 125 日均线的偏离，均线上方 10% → 0 分，下方 15% → 100 分（线性截断）
- 波动率：沪深300 近 20 日已实现波动年化，15% → 0 分，35% → 100 分
- 宽度：全市场站上 20 日均线的个股占比，70% → 0 分，15% → 100 分
- 涨跌停：跌停数 ÷（涨停数 + 跌停数），20% → 0 分，80% → 100 分（涨跌幅 ≥9.8% 计）
- 新高新低：（120 日新低家数 − 新高家数）÷ 有效个股数，−10% → 0 分，+30% → 100 分
- 合成分 = 五项算术平均

## 参数

- 分档：<25 极度贪婪 · 25-45 偏热 · 45-55 中性 · 55-75 偏恐慌 · ≥75 极度恐慌
- 基准指数：000300.SH

## 更新频率

交易日收盘后约 18:30 出当日值；盘中有近似快照（标 intraday）。

## 局限

- 没有期权、信用利差、国债避险数据，A 股以涨跌停代替期权情绪。
- 贪婪端在 2015、2021 两次大顶并未给出极低分（当时约 20 / 29），不能当见顶信号。
- 自相关高（约 0.81），日频足够，分钟级没有增量信息。

## 历史验证

- ≥75 的触发日历史上全部落在真实危机阶段；随后 20 日买宽基指数相对基准平均超额约 +11.5%（样本少，属方向证据）。
- 「越恐慌越该重仓」不成立：80 以上的后续收益并不比 75-80 更高。
